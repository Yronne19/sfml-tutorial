1. Set up SFML 3.1.0

SFML 3 needs a C++17 compiler. The easiest way to get it is CMake, which downloads and builds SFML for you.


  
Put your images, fonts and sounds next to the executable (or use full paths). SFML 3 loads files through constructors that throw an exception if the file is missing, so a wrong path tells you right away.
